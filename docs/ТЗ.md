## 1. Назначение и цели проекта

Целью проекта является разработка программной реализации настольной игры «Бантуми» (Kalah / Манкала) в виде клиент-серверного приложения. Бэкенд реализует игровую логику и предоставляет REST API с сохранением состояния в базе данных PostgreSQL. Фронтенд — десктопное приложение с графическим интерфейсом, взаимодействующее с бэкендом по HTTP.

Игра поддерживает два режима: PvP (два игрока) и PvE (игрок против искусственного интеллекта).

## 2. Требования к функциональности

### 2.1 Игровая логика (бэкенд)
| № | Требование |
|---|-----------|
| Ф-01 | Инициализация доски с N камнями в каждой из 12 лунок (N = 3–6) |
| Ф-02 | Раскладывание камней против часовой стрелки с пропуском Калаха противника |
| Ф-03 | Бонусный ход при попадании последнего камня в свой Калах |
| Ф-04 | Захват камней при попадании последнего камня в пустую лунку своей стороны |
| Ф-05 | Определение конца игры и автоматический сбор оставшихся камней |
| Ф-06 | Подсчёт итогового счёта и определение победителя (в т.ч. ничья) |
| Ф-07 | Отмена последнего хода (Undo) через снимки состояния в БД |
| Ф-08 | Режим PvE: ход ИИ выполняется автоматически после хода игрока |
| Ф-09 | ИИ выбирает ход на основе алгоритма Minimax с альфа-бета отсечением |

### 2.2 REST API (бэкенд)
| № | Метод | Эндпоинт | Описание |
|---|-------|----------|---------|
| А-01 | GET  | `/api/v1/game/state`                     | Получить текущее состояние игры |
| А-02 | POST | `/api/v1/game/new?stones={n}&mode={m}`   | Начать новую партию (mode: PVP / PVE) |
| А-03 | POST | `/api/v1/game/move/{pit}`                | Сделать ход из лунки pit |
| А-04 | POST | `/api/v1/game/undo`                      | Отменить последний ход |

### 2.3 База данных (бэкенд)
| № | Требование |
|---|-----------|
| Б-01 | Хранение состояния партии в таблице `games` (PostgreSQL) |
| Б-02 | Хранение каждого хода в таблице `moves` (One-to-Many к games) |
| Б-03 | Каждый `Move` содержит снимок доски для поддержки Undo |
| Б-04 | Таблицы создаются автоматически при запуске (Hibernate DDL auto) |

### 2.4 Графический интерфейс (фронтенд)
| № | Требование |
|---|-----------|
| Ф-10 | Отображение игровой доски: 12 лунок и 2 Калаха |
| Ф-11 | Количество камней в каждой лунке в реальном времени |
| Ф-12 | Подсветка последней лунки после хода |
| Ф-13 | Индикатор текущего хода (Игрок 1 / Игрок 2) |
| Ф-14 | Журнал ходов с отметкой бонусных ходов и захватов |
| Ф-15 | Диалог с результатом по окончании игры |
| Ф-16 | Кнопки «Новая игра» и «Отменить ход» |
| Ф-17 | Выбор количества камней в лунке (3–6) |
